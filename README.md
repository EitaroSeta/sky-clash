# SKY CLASH / スカイクラッシュ

浮遊島でCPUと戦う、オリジナルの対戦アクションゲームです。既存ゲームのキャラクター、画像、音楽は使用していません。外部ライブラリーやインターネット接続は不要です。

## PCで遊ぶ

`index.html` をブラウザーで開くだけで遊べます。`PLAY.bat` からも起動できます。

## スマホで遊ぶ

1. PCで `PLAY.bat` をダブルクリックします（Python 3が必要です）。
2. PCとスマホを同じWi-Fiに接続します。
3. 起動したウィンドウの `Phone (same Wi-Fi)` のアドレスをスマホのSafari / Chromeで開きます。
4. Windowsのファイアウォールの確認が表示された場合、信頼するプライベートネットワークでのみ許可してください。

スマホでは画面下のボタンで操作します。横向きにするとステージが広く見えます。縦向きにも対応しています。ゲーム中は起動ウィンドウを開いたままにします。終了するにはウィンドウで Ctrl+C を押してください。ゲストWi-Fiなど端末間通信が制限されたネットワークでは接続できない場合があります。複数のアドレスが出た場合はWi-Fiアダプターのアドレスを使ってください。

## 操作

| アクション | PC | スマホ |
|---|---|---|
| 移動 | A / D または ← / → | ◀ / ▶ |
| 2段ジャンプ | W / ↑ / Space（1回ずつ押す） | ↑（1回ずつタップ） |
| 通常攻撃 | J | 撃 |
| 必殺技 | K | 技 |
| ガード | L / Shift（長押し） | 盾（長押し） |
| 一時停止 | Esc / 右上のⅡ | 右上のⅡ |

相手にダメージを与えるほど吹き飛ばしが強くなります。画面外へ落ちるとストックを1つ失い、3つ失うと負けです。制限時間は3分。時間切れはストックが多い方、同数ならダメージが少ない方が勝ちです。両方同じなら引き分けです。

必殺技は弾を放ち、空中では着地まで1回だけ上昇して復帰を助けます。必殺技は約1.35秒の再使用待ちがあります。ガードは地上でのみ使え、使いすぎると壊れて一時的に動けなくなります。足場は下から飛び乗れます。復帰直後は短時間無敵です。

CPUの強さは3段階。バトル開始操作でBGMと効果音が有効になります。右上の音ボタンで消音、♫メニューでBGMとSEの音量を個別に調整できます。タブを切り替えると自動で一時停止します。

## ファイル

- `index.html`：画面とメニュー
- `style.css`：レスポンシブな表示
- `game.js`：描画、物理、CPU、タッチ操作、効果音
- `serve.py` / `PLAY.bat`：同じWi-Fiのスマホから接続するための起動ファイル

オンライン対戦機能はありません。1人対CPUのゲームです。


## CELESTIAL RUINS 更新

夕日の雲海、浮遊する城跡、滝と軌道リングを重ねたオリジナルステージです。左右の中段足場がゆっくり上下し、上段を含む3段の足場で空中戦ができます。

- W / ↑ はジャンプ兼上方向入力。押しながら J で上斬り。S / ↓ ＋ J は下斬りで、空中では下へ叩き落とします。スマホは左側 ↑↓ と撃を組み合わせます。
- S / ↓ は落下中の急降下、足場上ではすり抜けです。メインの島はすり抜けません。
- L / Shift ＋ 左右、または盾＋左右で無敵回避。再使用まで約0.9秒。
- 島の端へ落下しながら近づくと崖につかまります。ジャンプや上入力で復帰、下入力で手を離します。連続つかまりには待ち時間があります。
- 約12秒ごとに結晶が降ってきます。緑は25%回復、金は8秒間攻撃力上昇。触れると自動取得します。
- 足場の上下とキャラクターの乗車を同期。頭から足まで弾の当たり判定があり、被弾すると攻撃動作が中断されます。

## 溜めスマッシュ
地上で C またはスマホの「溜」を長押しし、離すと強い斬撃を放ちます。最大1.2秒まで溜められます。被弾、ジャンプ、中断時は溜めを解除します。


## サウンド
オリジナルの132 BPM・16小節のシンセBGMを内蔵。コード、ベース、ドラム、メロディーを重ね、Web Audioでリアルタイム生成します。斬撃・打撃・ガード・必殺技・撃墜には専用の多層SEを使用します。外部音源の読み込みは不要です。スマホでは音を出すためにバトル開始ボタンのタップが必要です。
